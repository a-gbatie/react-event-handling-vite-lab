# React Password Input Lab

## Project Description

This React application demonstrates event handling using a password input field and a submit button.

The password input logs a message when the user types, while the submit button logs messages when the mouse enters or leaves the button.

## Technologies Used

- React
- JavaScript
- JSX
- Vite
- Vitest
- React Testing Library

## Setup and Installation

Clone the repository and navigate into the project directory.

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Running Tests

Run the automated tests:

```bash
npm test
```

Alternatively:

```bash
npx vitest run
```
